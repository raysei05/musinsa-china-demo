# MUSINSA 차이나 · Vercel 배포 프로젝트

기존 상품 사진 21종(패션 15개, 뷰티 6개)과 UI를 유지하고, OpenAI 기반 사진 분석·상황별 코디를 연결한 프로젝트입니다. 등록 카탈로그 안에서 유사 상품을 추천합니다. 외부 쇼핑몰·Google Lens 검색 연동은 포함하지 않습니다.

## Vercel에 올리기

1. 이 폴더 전체를 GitHub 저장소에 올리고 Vercel에서 Import합니다. HTML 하나만 업로드하지 마세요.
2. Framework Preset은 `Other`, Output Directory는 `public`입니다. 설치할 외부 패키지나 빌드 명령은 없습니다. `vercel.json`이 포함되어 있습니다.
3. Vercel 프로젝트의 Settings → Environment Variables에 다음을 등록합니다.
   - `OPENAI_API_KEY`: 본인의 OpenAI API 키 (서버 전용)
   - `OPENAI_MODEL`: `gpt-4.1-mini` (선택, 생략해도 동일)
4. 키를 사용할 환경(Production, Preview)을 선택하고 배포합니다. 이미 배포한 뒤 키를 추가했다면 다시 배포합니다.
5. 사이트의 AI 코디 → 예시 사진 사용 → 왼쪽 인물 → 분석 버튼으로 확인합니다. 이후 다른 사진과 상황별 코디도 확인하세요.

또는 로그인된 Vercel CLI에서 이 폴더를 기준으로 `vercel`로 미리보기 배포, 검증 후 `vercel --prod`로 배포할 수 있습니다.

## 작동 방식

- 사진 업로드 → 브라우저에서 JPEG로 리사이즈 → `/api/analyze` → OpenAI Responses API → 관찰한 옷과 유사 상품 카드 표시
- 여러 인물이 있는 사진은 전체/왼쪽/오른쪽 인물을 선택합니다. 예시 사진은 왼쪽 인물이 기본입니다.
- 사진에 보이지 않는 신발은 추정하지 않도록 요청합니다. 유사 상품이 없으면 관찰 내용과 함께 해당 사실을 표시합니다.
- 상품 ID는 서버 카탈로그로 검증하고, 중복·존재하지 않는 상품·예산 초과 상품을 제외합니다. 가격 합계는 서버와 화면에서 실제 카탈로그 기준으로 계산합니다.
- 사진 분석 버튼에는 사진이 OpenAI로 전송된다는 설명이 있습니다. 앱은 사진을 저장하지 않으며 OpenAI 요청은 `store:false`입니다. 이것은 OpenAI 측의 모든 보관 정책을 변경한다는 의미가 아닙니다.
- API 키를 공개 HTML, 브라우저 코드, Git 저장소에 넣지 마세요. OpenAI 호출에는 해당 계정의 API 사용료가 적용됩니다.
- 매장·재고·픽업·장바구니는 기존과 같은 시연 기능입니다.

## 파일

- `public/index.html`: 기존 화면
- `public/ai.js`, `public/ai.css`: 실제 분석 결과 화면·업로드·요청 처리
- `public/assets/`: 기존 생성 상품 사진과 예시 사진 (원본 데이터에서 추출)
- `api/analyze.js`: Vercel 서버 함수, 서버 전용 API 호출
- `lib/catalog.json`: 상품 정보·가격·외형 특징
- `.env.example`: 필요한 변수 이름, 실제 키 없음
- `dev.mjs`: 로컬 검증용 HTTP 서버

## 로컬 확인

Node.js 22 이상에서 `npm test`로 서버 검증을 실행합니다.
`npm run dev`로 서버를 띄우면 `http://127.0.0.1:3000`에서 화면과 API를 확인할 수 있습니다.
실제 모델 요청을 로컬에서 확인하려면 키를 환경변수로 등록한 터미널에서 실행하세요. `.env.example`을 복사하는 것만으로 `npm run dev`가 `.env`를 자동 로드하지는 않습니다.

## 검증과 한계

서버 검증 8개가 통과했습니다. 정상 이미지/텍스트 요청, 키 미설정, 잘못된 입력, 다른 출처의 요청 거부, 모델 오류·사용 한도·시간 초과, 유효 상품 검증과 합계를 모의 응답으로 확인했습니다. 실제 OpenAI API 키가 제공되지 않아 유료 모델 호출과 Vercel 실배포 검증은 수행하지 않았습니다. 이미지 분석에는 오인식이 있을 수 있으며 상품은 정확한 실물 식별이 아닌 유사 디자인 추천입니다.
